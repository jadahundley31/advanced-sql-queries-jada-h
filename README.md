○ What did you learn?
WHERE filters individual rows, runs before the GROUP BY keyword, and can filter individual order amounts.	
HAVING filters group results, runs after the GROUP BY keyword, and can filter totals calculated using the aggregate function SUM().

○ What was most challenging?
I did struggle understanding the difference between WHERE and HAVING, but understanding the syntax and where to place them helped me
understand the difference. However, the overall challenge for me is trying to figuring out when to use which subqueries.
